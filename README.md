\# Malaysian Hardware DRAM \& Component Price Inflation Analysis (2026)



\## Executive Summary

An end-to-end data analytics portfolio project tracking consumer hardware price surges, supply chain inflation, and component cost anomalies within the local Malaysian market. This project evaluates price trajectories against a standard

15% procurement risk threshold.



\## Tech Stack \& Architecture

* Data Extraction \& ETL: Python ('pandas', 'sqlite3') for data ingestion, cleaning and transformation.
* Data Modeling: Relational Schema tracking brand models, retailer categories, and historical price changes.
* Visuals \& BI: Tableau Public Desktop for execution-ready dashboarding, continuous exact timelines, and cross-filtering interactivity.



\## Key Insights

* Peak Price Inflation: Identified maximum percentage spikes across high-demand RAM and component models.
* Procurement Risk Threshold: Visualized a continuous 15% baseline to highlight periods of severe market volatility.
* Cost Impact: Mapped average MYR price increases to provide grounded budgeting context for local consumers and builders.
